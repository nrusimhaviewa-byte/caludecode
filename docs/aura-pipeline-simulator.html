Project AURA — the safety architecture, running in your browser.

Project AURA's v2 proposal replaced nine unlabeled agent boxes with contracts: every agent declares what it reads, what structured object it emits, and what it's forbidden from doing. This simulator makes that contract visible — configure an applicant, run the pipeline, and watch a WITHHELD field actually disappear from every downstream agent's context instead of just being flagged.

Problem

Account-opening pipelines that name agents (KYC, AML, Risk) without defining what evidence gates each decision are impossible for a judge — or a regulator — to trust. v1 of this proposal was exactly that.

Solution

Data Sentinel is a validation gate, not a vibe: four deterministic checks (missing, stale, low-confidence, inconsistent) produce PASS / WITHHOLD / ESCALATE, and WITHHOLD fields become structurally inaccessible downstream.

Why this demo is honest

No agent, LLM call, or core-banking system is real. This is the deterministic threshold logic from the v2 spec, executed in JS against synthetic applicants — proving the design, not the model.

    What this simulator is and isn't
    
      
      
    • Every check here is the deterministic threshold logic described in Project AURA v2 — no LLM call, no ADK agent, no Gemini API, no core-banking system is actually invoked.
      • 
      
    • Cross-source reconciliation is "LLM-assisted, schema-constrained" in the real design; this demo runs it as a plain equality check between CRM and document ownership type as a stand-in.
      • 
      
    • The confidence bands (<0.55 WITHHOLD, 0.55–0.79 ESCALATE, ≥0.80 PASS) resolve an overlap between the v2 spec's two threshold tables into one consistent rule — treat it as a proposed reading, not a ratified one.
      • 
      
    • The spec defines APPROVE (by construction) and ESCALATE (human-routed) paths in detail but never specifies a deterministic REJECT trigger — this demo doesn't invent one either, matching that gap rather than papering over it.
      • 
      
    • All applicant data on this page is synthetic and entered by you; nothing is transmitted anywhere.
